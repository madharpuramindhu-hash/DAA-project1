The algorithm

Let L[i][j] be the LCS length of the first i tokens of A and the first j tokens of B.

If A[i] = B[j]: L[i][j] = L[i-1][j-1] + 1
Otherwise: L[i][j] = max( L[i-1][j], L[i][j-1] )

Starting at L[n][m] and walking back through the table recovers the common tokens. Time complexity is O(n × m), and so is the memory for the table.
